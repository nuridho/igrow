File setelannya belum punya SETUP_DONE, jadi script masih masuk Jalur A. Itu aman karena langkah yang beres dilewati. Supaya langsung ke menu, pilih salah satu, cukup sekali:

        
bash igrowctl.sh all
# atau
echo 'SETUP_DONE=1' >> ~/.config/igrow/setup.env
