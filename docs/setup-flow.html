Simulator Setup iGROW

Jalankan setupvps.sh dan igrowctl.sh di sini tanpa menyentuh VPS. Teks di terminal disalin dari script aslinya; kamu bisa memilih perintah, mengubah isi setup.env, mengisi sendiri pertanyaannya, atau memancing error.

Kartu di bawah bisa diklik: simulator langsung menjalankan jalur yang dipilih.

Langkah

    Nama, versi, dan keluaran perintah Hermes (daftar cron, wizard) hanya contoh fiktif. Teks tampilan script disalin dari script aslinya.

    Kasus yang perlu diingat

    Perintah langsung selalu melewati menu

    Cocok untuk alias di laptop. Penanda SETUP_DONE tidak dicek. Klik chip perintah di simulator untuk melihatnya.

    deploysama dengan menu 1
    statussama dengan menu 2
    updatesama dengan menu 3
    step 6 / 7 / 8sama dengan menu 4 / 5 / 6 (tanpa tawaran hapus token)
    allJalur A, walaupun penanda sudah ada
    helppenjelasan tiap pilihan

    VPS yang setupnya dibuat sebelum ada menu

    File setelannya belum punya SETUP_DONE, jadi script masih masuk Jalur A. Itu aman karena yang sudah ada dilewati. Supaya langsung ke menu, jalankan bash igrowctl.sh all sekali, atau tambahkan SETUP_DONE=1 ke setup.env.
