Satu cerita, apa saja yang berubah

Contoh pesan tanggal 20 September 2026. Satu cerita menyentuh enam file, tapi yang kamu lihat di Telegram cuma balasan di paling bawah.

Kamu · TelegramKemarin server production down 2 jam. CPU 100% gara-gara backup MySQL jalan pas jam sibuk. Akhirnya matiin backup, server normal lagi.

  1. Tentukan career aktif

    Cari about.md yang belum punya tanggal selesai. Ketemu satu: nama folder lengkapnya dipakai di semua path.

    wiki/careers/career-1-acme-sysadmin/about.md

  2. Tulis note incident

    "Kemarin" diubah jadi tanggal kejadian (19 Sep), data sensitif diredaksi, lalu self-check sebelum file ditulis.

    knowledge/incidents/2026-09-19-mysql-backup-cpu-spike.md

  3. Link balik di note lama

    Note baru menaut ke cpu-spike-triage, jadi note lama itu dapat 1 baris di See Also. Tanggal updated-nya tidak berubah.

    knowledge/cpu-spike-triage.md

  4. Tambah skill yang terlihat

    Skill baru ditambah per tag (linux: cek jadwal cron, performance: jadwalkan ulang job berat); yang sudah ada tidak ditulis ulang.

    wiki/careers/career-1-acme-sysadmin/skills.md

  5. Catat di daftar isi

    Baris note baru, baris placeholder untuk backup-scheduling yang belum ada, dan tanggal baris skills.md.

    wiki/_index.md

  6. Tulis jurnal

    Satu baris di log, termasuk note lama yang dapat link balik.

    log.md
